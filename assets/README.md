# Tokoro runtime assets

`intro/tokoro-ident.wav` is an original, voice-free launch ident created for Tokoro. It contains no third-party sample file. It is distributed under the repository's `MIT OR Apache-2.0` terms.

Sound is disabled by default, plays at most once per interactive launch, and fails silently. CLI, JSON, CI, redirected terminals, and `TERM=dumb` do not play it.
