# Code of conduct

Tokoro contributors are expected to make participation respectful, constructive, and safe.

## Expected behavior

- Discuss ideas and code without personal attacks.
- Give specific, actionable feedback.
- Respect different experience levels, backgrounds, and communication styles.
- Protect private data and security reports.
- Correct mistakes openly and accept reasonable moderation.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, sexualized attention, sustained disruption, and publishing another person's private information are not accepted in project spaces.

## Enforcement

Report conduct concerns privately through the repository maintainers or GitHub's reporting facilities. Maintainers may edit or remove content, close or lock discussions, reject contributions, or temporarily or permanently restrict participation. Reports will be handled as privately and fairly as practical.

This policy applies to repository activity and other spaces where someone is representing the project.
